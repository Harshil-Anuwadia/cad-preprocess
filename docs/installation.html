Foundation / Installation

Installation

CAD Preprocess can be installed as a native Linux package for production stability or via pip for development workflows.

Native Linux Packages (Recommended)

Native packages include all required DICOM decompression codecs (pylibjpeg, gdcm) pre-configured. This is the most reliable way to ensure consistency across environments.

Arch Linux

Build and install using the standard PKGBUILD or the bundled installer:

# Method A: Standard build
makepkg -si

# Method B: Self-contained bundle builder
./build_arch.sh
sudo pacman -U cad-preprocess-bundled-0.1.0-1-x86_64.pkg.tar.zst

Debian / Ubuntu

Build a fully self-contained .deb package that bundles its own dependencies:

# Generate and install the .deb package
./build_deb.sh
sudo dpkg -i cad-preprocess_0.1.0_all.deb

Python Package (pip)

For research and local development, install the library directly into your virtual environment:

# Core installation
pip install cad-preprocess

# Optional: Add decompression support for medical codecs
pip install pylibjpeg pylibjpeg-libjpeg pylibjpeg-openjpeg python-gdcm
💡 Verification
Run cad-preprocess --version to verify the installation. You should see cad-preprocess 0.1.0.

System Requirements

Requirement Compatibility Role
Python >= 3.9 Runtime Environment
pydicom >= 2.3.0 DICOM I/O
numpy >= 1.21.0 Array Processing
scikit-image >= 0.19.0 Advanced Filters
