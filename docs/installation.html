Foundation / Installation

Installation

CAD Preprocess can be installed as a native Linux package or via pip for development workflows.

Native Linux Packages

Native packages include bundled DICOM decompression codecs (pylibjpeg, gdcm). This is the recommended method for production environments to ensure consistent behavior across different systems.

Arch Linux

Build and install using the provided PKGBUILD or the bundled installer script:

# Method A: Standard makepkg build
makepkg -si

# Method B: Bundled installer builder
./build_arch.sh
sudo pacman -U cad-preprocess-bundled-0.1.0-1-x86_64.pkg.tar.zst

Debian / Ubuntu

Generate a self-contained .deb package that includes all dependencies:

# Build and install the Debian package
./build_deb.sh
sudo dpkg -i cad-preprocess_0.1.0_all.deb

Python Package (pip)

Install the library directly into your Python environment. This is suitable for research and local script development.

# Base installation
pip install cad-preprocess

# Optional: Medical imaging codecs
pip install pylibjpeg pylibjpeg-libjpeg pylibjpeg-openjpeg python-gdcm
Verification
Verify the installation by running cad-preprocess --version. The output should be cad-preprocess 0.1.0.

Technical Requirements

Package Compatibility Function
Python >= 3.9 Base Environment
pydicom >= 2.3.0 DICOM Handling
numpy >= 1.21.0 Numerical Arrays
scikit-image >= 0.19.0 Image Processing
