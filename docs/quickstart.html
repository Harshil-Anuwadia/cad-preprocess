Foundation / Quick Start

Quick Start

Get up and running with CAD Preprocess in 5 minutes. This guide covers basic CLI operations and Python API integration.

Command Line Interface

Batch Directory Processing

Process an entire local directory and write the standardized output to a new folder:

cad-preprocess -i /data/scans -o /data/processed

Configured Pipeline

Apply specific windowing, normalization, and resizing settings defined in a YAML file:

cad-preprocess -i ./dicoms -o ./output -c config.yaml

Simulated Execution (Dry Run)

Verify file discovery and configuration mapping without writing any data to disk:

cad-preprocess -i ./dicoms -o ./output --dry-run

CT Windowing Presets

# Lung windowing (-600, 1500)
cad-preprocess -i ./dicoms -o ./output --window-center -600 --window-width 1500

# Soft tissue windowing (40, 400)
cad-preprocess -i ./dicoms -o ./output --window-center 40 --window-width 400

Python API

Single-Scan Inference Bridge

Use the preprocess utility for lightweight single-file transformations:

from cad_preprocess import preprocess

# Returns a ProcessingResult object containing the image array and metadata
result = preprocess("scan.dcm", "output/")

print(f"Matrix Size: {result.image.shape}")
print(f"SOP UID: {result.sop_instance_uid}")

Pipeline Reproducibility

Ensuring that training and inference environments use identical configurations:

from cad_preprocess import CADPreprocessor

# Load the versioned configuration
processor = CADPreprocessor.from_config("stable_v1.yaml")

# The config_hash serves as a unique fingerprint for the pipeline
print(f"Pipeline Signature: {processor.config_hash}")

# Execute batch process
results = processor.process_directory("input_dicoms/", "output_data/")

Output Architecture

CAD Preprocess generates a structured, auditable output directory:

output/
├── images/                    # Standardized images (PNG/NumPy)
├── metadata/                  # Profile-based JSON/CSV data
├── logs/                      # Detailed processing statistics
└── manifest.json              # Verifiable pipeline manifest
