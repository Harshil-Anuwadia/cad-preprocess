Quick Start

This guide demonstrates basic CLI operations and Python API integration for CAD Preprocess.

Command Line Interface

Batch Directory Processing

Process a directory of DICOM files and output standardized images and metadata:

cad-preprocess -i /data/scans -o /data/processed

Configured Processing

Load specific pipeline settings from a YAML configuration file:

cad-preprocess -i ./dicoms -o ./output -c config.yaml

Dry Run Simulation

Verify file discovery and configuration mapping without writing output:

cad-preprocess -i ./dicoms -o ./output --dry-run

Windowing Presets

# Lung Window (-600, 1500)
cad-preprocess -i ./dicoms -o ./output --window-center -600 --window-width 1500

# Soft Tissue Window (40, 400)
cad-preprocess -i ./dicoms -o ./output --window-center 40 --window-width 400

Python API

Processing Utility

Use the preprocess function for direct file transformations:

from cad_preprocess import preprocess

# Process single file
result = preprocess("scan.dcm", "output/")

print(f"Shape: {result.image.shape}")
print(f"UID: {result.sop_instance_uid}")

Pipeline Consistency

The CADPreprocessor class enables configuration-driven workflows:

from cad_preprocess import CADPreprocessor

# Load settings
processor = CADPreprocessor.from_config("stable_v1.yaml")

# Signature tracking for reproducibility
print(f"Hash: {processor.config_hash}")

# Batch execution
results = processor.process_directory("input_dicoms/", "output_data/")

Output Structure

CAD Preprocess generates a structured directory for processed data:

output/
├── images/                    # Processed images (PNG/NumPy)
├── metadata/                  # JSON/CSV metadata records
├── logs/                      # Execution logs
└── manifest.json              # Pipeline manifest
