Section 01

Overview & Pipeline Philosophy

Radiology machine learning models are highly sensitive to subtle discrepancies in voxel array representation. Small variances in spatial resolution interpolations, Hounsfield Unit calibrations, or clipping thresholds during training versus clinical deployment can trigger silent diagnostic degradation in production.

The cad-preprocess package addresses this challenge. By centralizing pipeline parameters inside standard configurations, it guarantees that patient datasets are processed deterministically across PyTorch training sequences, FastAPI clinical inference endpoints, and local PyQt6 visual clients.

Metadata Extraction

1. Linear Rescaling (Hounsfield Unit Conversion)

For CT modalities, pixel matrices represent physical voxel densities that must be converted to physical Hounsfield Units (HU) using the Rescale Slope and Intercept attributes embedded within the DICOM Part 10 metadata header:

Linear transformation formula: $$HU = (Raw\_Voxel\_Value \times RescaleSlope) + RescaleIntercept$$

2. Intensity Windowing Mechanics

Windowing isolates specific tissue densities (e.g. bones, lung parenchyma, or soft brain matter) by mapping the designated input range to a standard output scale.

Let window center be \(C\) and window width be \(W\). The minimum and maximum clip bounds are: $$Bounds_{Min} = C - (W / 2), \quad Bounds_{Max} = C + (W / 2)$$ Voxel values are clipped: $$Clipped = \min(\max(Input, Bounds_{Min}), Bounds_{Max})$$

3. Intensity Normalization Algorithms

Normalized values scale feature representations to stable coordinates, optimizing training convergence:

Min-Max Scaling: Map intensity values to \([0.0, 1.0]\). $$Normalized = \frac{Pixel - Min}{Max - Min}$$
Z-Score Standardization: Scale by mean (\(\mu\)) and standard deviation (\(\sigma\)). $$Standardized = \frac{Pixel - \mu}{\sigma}$$

Sequential Processing Pipeline

Every loaded file undergoes a deterministic sequence of transformations inside the processing engine:

01
Load binary & metadata
Retrieves tags using pydicom, verifying header structural integrity.
02
Extract raw array
Loads the PixelData array safely, automatically handling byte order.
03
Apply Slope & Intercept
Applies RescaleSlope and RescaleIntercept tags to yield physical units (e.g., Hounsfield Units).
04
Intensity Windowing
Applies custom center/width limits or extracts standard VOI LUT tags from DICOM metadata.
05
Normalize Pixels
Scales array values to the min-max [0.0, 1.0] range or applies Z-Score mean/standard deviations.
06
Resize & Padding
Resizes using bilinear/bicubic paths, optionally applying neutral borders to preserve aspect ratio.
Section 02

Installation Guide

CAD Preprocess requires Python 3.9 or higher. You can install it directly via pip or bundle it within isolated project environments.

Virtual Environment Installation

# Create and activate python virtual environment
python3 -m venv venv
source venv/bin/activate

# Install Core Library
pip install --upgrade pip
pip install cad-preprocess

Optional GUI Support

To use the interactive visual Explorer workbench, install PyQt6 graphical packages alongside the core modules: 

pip install "cad-preprocess[gui]"

Native Binary Packaging

For clinical servers isolated from public internet repositories, we provide pre-packaged self-contained installers that bundle core libraries and compression codecs (such as pylibjpeg and gdcm):

  • Ubuntu/Debian: sudo dpkg -i cad-preprocess_1.0.0_all.deb
  • Arch Linux: sudo pacman -U cad-preprocess-bundled-1.0.0-1-x86_64.pkg.tar.zst
Decompression Plugins

Many clinical scanners save files with compressed transfer syntaxes (e.g. JPEG Lossless Process 14 or JPEG 2000). To avoid unreadable stream crashes, install standard codec libraries:
pip install pylibjpeg pylibjpeg-libjpeg pylibjpeg-openjpeg python-gdcm

Section 03

Quickstart & Basic Usage

CAD Preprocess can be used as a simple CLI utility or integrated programmatically inside your backend scripts. 

from cad_preprocess import preprocess, CADPreprocessor

# 1. Quick programmatic preprocessing
result = preprocess(
    input_path="/data/dicoms/",
    output_path="/data/processed/",
    config="pipeline.yaml"
)
print(f"Total files processed successfully: {result.processed_count}")

# 2. Or orchestrate via preprocessor class
preprocessor = CADPreprocessor(config_path="pipeline.yaml")
batch_res = preprocessor.process_batch(["file1.dcm", "file2.dcm"])
# Process folder with a specific YAML pipeline file
cad-preprocess --input /data/dicoms --output /data/output --config config.yaml

# Perform quick custom overrides directly from bash
cad-preprocess -i ./raw_dcm -o ./out --target-size 512 512 --window-center 40 --window-width 400 --overwrite
input:
  validate: true
  check_pixel_data: true

preprocessing:
  windowing:
    strategy: "fixed_window"
    window_center: 40
    window_width: 400
  normalization: "min_max"
  resizing:
    enabled: true
    target_size: [1024, 1024]
    keep_aspect_ratio: true
    interpolation: "bilinear"

output:
  naming_policy: "sop_instance_uid"
  image_format: "png"
Section 04

Architecture & Code Layout

CAD Preprocess is structured in a highly modular, decoupled fashion. This directory map outlines the role and responsibility of each module in the core package:

File / Module Path Core Responsibility Primary Class/Function Exports
config.py Handles YAML file loading, default settings initialization, and strict type schema validation. Config, load_config(), PreprocessingSettings
preprocessing_engine.py The mathematical core. Executes HU scaling, window clipping, normalization, and image interpolation. PreprocessingEngine, WindowingConfig, NormalizationMethod
input_handler.py Handles folder discoveries, file listings, and safe byte header evaluations using pydicom. InputHandler, discover_dicom_files(), validate_dicom_file()
metadata_extractor.py Extracts patient profiles, scan geometric spacing, and custom machine learning clinical metadata tags. MetadataExtractor, MetadataProfile, ExtractionResult
output_writer.py Encodes processed NumPy matrices into PNG/JPEG formats or saves raw vectors as standard NPY files. OutputWriter, NamingPolicy, OverwritePolicy
logging_utils.py Provides runtime diagnostic logs, timings, performance telemetry counters, and exception decorators. CADPreprocessError, timed_operation(), setup_logging()
integration.py Orchestrates batch runs, calculates manifest SHA256 hashes, and checks mathematical pipeline consistency. CADPreprocessor, get_config_hash(), verify_preprocessing_consistency()
api.py High-level developer interface exposing unified functional entries. preprocess(), PreprocessingResult
explorer.py PyQt6 GUI application providing visual DICOM slide checks, metadata inspection, and slider parameters. launch_explorer(), ExplorerWindow

2. Input Verification API

Verify integrity and validate raw DICOM files: 

from cad_preprocess import validate_dicom_file, discover_dicom_files

# Check if a single file is a valid readable DICOM
is_valid, error_msg = validate_dicom_file("/path/to/scan.dcm", check_pixel_data=True)
if not is_valid:
    print(f"DICOM Validation Failed: {error_msg}")

# Search a path recursively for valid DICOM file paths
dicom_paths = discover_dicom_files("/data/clinical_scans/", recursive=True)
print(f"Found {len(dicom_paths)} valid scan files")

3. Processing Orchestration & Consistency Verification

When deploying neural models clinically, ensuring pipeline parameters haven't changed is crucial. Use pipeline hashing and manifest checks to verify consistency: 

from cad_preprocess import get_config_hash, verify_preprocessing_consistency

# Generate a SHA-256 hash representing current active pipeline configuration
config_hash = get_config_hash("pipeline.yaml")
print(f"Configuration Security Signature: {config_hash}")

# Verify that processed outputs strictly match the active pipeline YAML file
is_consistent, report = verify_preprocessing_consistency(
    manifest_path="/data/processed/manifest.json",
    config_path="pipeline.yaml"
)
if not is_consistent:
    print("Warning: Pipeline inconsistency detected!")
    print(f"Mismatched keys: {report.mismatched_keys}")

4. Programmatic Engine Classes

PreprocessingEngine(config: PreprocessingConfig)

Transforms raw datasets into finalized arrays.

  • __init__(config): Instantiates the transformation engine with active parameters.
  • process(dataset: pydicom.Dataset|str|Path) -> PreprocessingResult: Executes transformations sequentially. Returns array results alongside applied scaling metadata.

MetadataExtractor(profiles: List[str], additional_fields: List[str] = [])

Extracts tags out of binary datasets into structured dictionaries based on active profiles.

  • extract(dataset: pydicom.Dataset) -> ExtractionResult: Resolves tags based on active profiles (e.g. Patient ID, Slice Thickness, Spacing, Modality).

OutputWriter(config: OutputConfig)

Writes standardized voxel matrix images and parsed metadata to disk.

  • write(image: np.ndarray, metadata: dict, output_name: str) -> WriteResult: Persists outputs into standardized folders based on active naming and overwrite policies.
Section 08

Clinical Production Pipelines

Use these production-grade templates to integrate standard clinical preprocessing directly inside deep learning training loops and web deployment services.

1. High-Performance PyTorch Dataset

This thread-safe PyTorch `Dataset` loads and normalizes raw patient files on-the-fly, featuring caching and error isolation: 

import torch
from torch.utils.data import Dataset
import logging
from pathlib import Path
from cad_preprocess import PreprocessingEngine, load_config, validate_dicom_file

logger = logging.getLogger(__name__)

class ClinicalDicomDataset(Dataset):
    def __init__(self, file_paths, config_path, cache_in_memory=False):
        self.file_paths = [Path(p) for p in file_paths]
        # Load centralized configuration settings safely
        raw_cfg = load_config(config_path)
        self.engine = PreprocessingEngine(config=raw_cfg.preprocessing.to_preprocessing_config())
        self.cache_in_memory = cache_in_memory
        self.cache = {}

    def __len__(self):
        return len(self.file_paths)

    def __getitem__(self, idx):
        path = self.file_paths[idx]
        
        if self.cache_in_memory and path in self.cache:
            return self.cache[path]

        # Validate DICOM layout before processing
        is_valid, err = validate_dicom_file(path, check_pixel_data=True)
        if not is_valid:
            logger.error(f"Skipping corrupted scan {path.name}: {err}")
            # Fallback to a zero-filled tensor or raised error
            return torch.zeros((1, 512, 512), dtype=torch.float32)

        try:
            # Process pixels deterministically
            res = self.engine.process(path)
            if not res.success:
                raise RuntimeError(res.error_message)

            # Convert numpy float32 matrix to PyTorch image representation [1, H, W]
            tensor_img = torch.tensor(res.image, dtype=torch.float32).unsqueeze(0)
            
            if self.cache_in_memory:
                self.cache[path] = tensor_img
                
            return tensor_img
        except Exception as e:
            logger.error(f"Transformation failed on {path.name}: {str(e)}")
            return torch.zeros((1, 512, 512), dtype=torch.float32)

2. Keras / TensorFlow Batch Data Sequence

Standard Keras thread-safe Sequence pipeline designed for robust multi-threaded model fit cycles: 

import numpy as np
from tensorflow.keras.utils import Sequence
from cad_preprocess import PreprocessingEngine, load_config

class DicomBatchSequence(Sequence):
    def __init__(self, file_paths, config_path, batch_size=16):
        self.file_paths = file_paths
        self.batch_size = batch_size
        raw_cfg = load_config(config_path)
        self.engine = PreprocessingEngine(config=raw_cfg.preprocessing.to_preprocessing_config())

    def __len__(self):
        return int(np.ceil(len(self.file_paths) / float(self.batch_size)))

    def __getitem__(self, idx):
        batch_x = self.file_paths[idx * self.batch_size : (idx + 1) * self.batch_size]
        images = []

        for path in batch_x:
            res = self.engine.process(path)
            if res.success:
                # Add channel dimension: [H, W, 1]
                img_channel = np.expand_dims(res.image, axis=-1)
                images.append(img_channel)
            else:
                # Append neutral zero array in case of corruption
                images.append(np.zeros((512, 512, 1), dtype=np.float32))

        return np.array(images)

3. Production FastAPI Clinical Inference Service

An API service standardizing inbound patient scans on-the-fly for neural model inferences: 

import tempfile
from fastapi import FastAPI, UploadFile, File, HTTPException
from cad_preprocess import CADPreprocessor
import numpy as np

app = FastAPI(title="Clinical Standardizer", version="1.0.0")

# Instantiate global orchestrator with central configuration
preprocessor = CADPreprocessor(config_path="clinical_pipeline.yaml")

@app.post("/standardize-scan")
async def standardize_scan(file: UploadFile = File(...)):
    if not file.filename.endswith(".dcm"):
        raise HTTPException(status_code=400, detail="Invalid extension. Required DICOM file.")

    # Write temporarily to disk for safe processing
    with tempfile.NamedTemporaryFile(delete=False, suffix=".dcm") as temp_dcm:
        temp_dcm.write(await file.read())
        temp_path = temp_dcm.name

    try:
        # Preprocess using the central engine parameters
        res = preprocessor.engine.process(temp_path)
        if not res.success:
            raise HTTPException(status_code=422, detail=f"DICOM processing error: {res.error_message}")

        # Extract accompanying structural tags
        tags = preprocessor.extractor.extract_file(temp_path)

        return {
            "success": True,
            "patient_id": tags.get("PatientID", "Anonymous"),
            "slice_thickness": tags.get("SliceThickness", 1.0),
            "dimensions": res.image.shape,
            "normalized_mean": float(np.mean(res.image)),
            "matrix": res.image.tolist() # Ready to pipe directly to PyTorch or ONNX
        }
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

3. Custom Exception Tree & Remediation Paths

The diagnostics engine raises localized exceptions during validation and transformation phases. Here is how to diagnose and recover:

Exception Raised Root Failure Cause Clinical Mitigation Strategy / Fix
ValidationError File lacks standard 128-byte preamble or missing the "DICM" signature magic bytes. Skip file, or enable input.validate: false configuration override for non-standard scanners.
PreprocessingError The underlying pixel matrix is missing, or contains corrupted coordinate coordinates. Validate file integrity on PACS server or configure input.check_pixel_data: true to log and skip.
MetadataExtractionError Required tags (e.g. SliceThickness, SpacingBetweenSlices) are missing under active profiles. Utilize a more lenient profile (e.g. "minimal") or specify fallback values using additional_fields.
OutputError Failed to write standardized matrix due to full disk space or missing permission access. Check folder write permissions or configure output.overwrite_policy: overwrite to clean old files.
