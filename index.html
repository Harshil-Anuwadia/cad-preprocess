Documentation

CAD Preprocess is a technical utility for standardizing DICOM preprocessing in medical AI pipelines. It provides a reproducible interface for transforming raw DICOM data into standardized model inputs, ensuring consistency across training and inference environments.

Core Philosophy
The pipeline is built on the principle of deterministic processing. Every transformation is mapped and verified via configuration hashing, providing a unique signature for your data state.

Pipeline Capabilities

Native Decompression
Bundled support for JPEG Lossless, JPEG 2000, and RLE codecs without external dependencies.
Geometric Integrity
Aspect-ratio preservation and spatial context management during resizing and normalization.
Metadata Profiling
Extraction of patient, acquisition, and geometry tags into structured JSON and CSV formats.
Deterministic Execution
Configuration hashing ensures that processed outputs are fully auditable and reproducible.

Implementation Examples

Command Line Interface

# Batch process a local directory
cad-preprocess -i /data/raw -o /data/processed --config pipeline.yaml

# Apply windowing overrides
cad-preprocess -i ./input -o ./output --window-center 40 --window-width 400

Python API

from cad_preprocess import CADPreprocessor

# Initialize with versioned settings
processor = CADPreprocessor.from_config("v1_stable.yaml")

# Process single scan
result = processor.process("scan.dcm")
image_array = result.image

print(f"Pipeline Signature: {processor.config_hash}")
