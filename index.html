Documentation

CAD Preprocess is a high-performance Python utility designed to eliminate "preprocessing drift" in medical imaging AI. By providing a unified bridge between raw DICOM data and standardized model inputs, it ensures that training, inference, and clinical integration environments yield identical results.

💡 Unified Preprocessing
The core philosophy is reproducibility. Every transformation is tracked via configuration hashing, providing a verifiable signature for your data pipeline.

Pipeline Capabilities

🛡️
Native Decompression
Integrated support for JPEG Lossless, JPEG 2000, and RLE without external system dependencies.
📐
Geometric Integrity
Preserves aspect ratios and spatial context during resizing and normalization.
📊
Metadata Profiling
Structured extraction of patient, acquisition, and geometry tags into JSON/CSV formats.
🧪
Deterministic Output
Configuration hashing ensures that every processed image is reproducible and auditable.

Implementation Examples

Terminal (Batch Processing)

# Process an entire local directory with a YAML configuration
cad-preprocess -i /data/raw -o /data/processed --config pipeline.yaml

# Apply CT windowing overrides via CLI
cad-preprocess -i ./input -o ./output --window-center 40 --window-width 400

Python (API Integration)

from cad_preprocess import CADPreprocessor

# Initialize with a versioned configuration
processor = CADPreprocessor.from_config("v1_stable.yaml")

# Process single scan for inference
result = processor.process("scan.dcm")
image_array = result.image  # Ready for model forward pass

print(f"Pipeline Signature: {processor.config_hash}")
